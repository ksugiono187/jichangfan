## 🔌 连接与节点问题

**Q：为什么导入订阅后，点击测速全部显示 Timeout (超时)？**
*   **排查 1**：您的本地网络是否正常？请先关闭代理，确认您能正常打开百度等国内网站。
*   **排查 2**：您的设备系统时间是否准确？Vmess 等协议对时间要求极其严格，设备时间与标准时间误差不能超过 90 秒。请在系统设置中开启“自动同步网络时间”。
*   **排查 3**：您的机场套餐是否已经到期？或者流量已经用尽被系统切断？请登录机场后台检查账单和仪表盘。

**Q：昨天用得好好的，今天突然连不上了怎么办？**
这通常是因为不可抗力导致节点 IP 被封，或者服务商更换了服务器。
**解决方法极其简单：更新订阅。**
在 Clash 中点击配置上的刷新按钮；在小火箭中向右滑动您的订阅名称，点击“更新”。拉取最新的节点配置后即可恢复正常。

**Q：这么多节点，香港、日本、美国到底选哪个？**
*   **日常网页浏览 / 刷推特**：首选**香港 (HK)** 或 **台湾 (TW)** 节点。物理距离近，延迟极低，网页可谓秒开。
*   **看视频 / 玩游戏**：首选**日本 (JP)** 节点。带宽充足，且到国际各大机房的路由非常优秀。
*   **外贸 / 跨境电商**：首选**美国 (US)** 节点。北美地区的网络环境审查最少，对于注册海外账号（如 ChatGPT、TikTok）最不容易触发风控。

## 🚀 速度与流量问题

**Q：为什么我买的 1000M 宽带，用机场测速只有 50M？**
翻墙速度不仅取决于您的本地宽带，还受制于“木桶效应”。数据需要经过您本地的小区光纤 -> 运营商国际出口 -> 海底光缆 -> 机场海外服务器。任何一个环节拥堵都会导致降速。在晚高峰时期，能够稳定保持在 50Mbps（足够流畅看 4K 视频）以上的机场，就已经算得上是非常优质的中高端机场了。

**Q：节点后面的 “x0.2” “x1.5” 是什么意思？**
这是机场通用的**倍率计费模式**。
*   `x1.0`：标准倍率。您看了 1GB 的视频，套餐就扣除 1GB 流量。
*   `x0.2`：通常是冷门地区或直连低成本节点。您用了 1GB，套餐只扣除 0.2GB。
*   `x2.0` / `x5.0`：通常是极其昂贵的 IPLC 物理专线节点。速度极快、延迟极低，但成本高昂。您用了 1GB，套餐将扣除 2GB 到 5GB 的额度。如果您流量不富裕，请谨慎挂着高倍率节点下载大文件。

**Q：流量用不完，下个月会结转累加吗？**
绝大部分机场采用的都是“按月清零”制。就像您的手机流量套餐一样，无论上个月剩下多少，次月结账日都会强制清零并重新发放当月额度。所以建议大家根据自己的实际用量，按需购买，避免浪费。

## 📱 设备与安全问题

**Q：我可以把节点分享给我的朋友使用吗？**
**绝对不要这么做。**
所有的机场系统都有严格的“异常 IP 检测”与“设备并发数检测”。如果系统发现您的账号同时在广州、北京、纽约的多个不同 IP 下登录，系统会判定您的账号被盗或恶意分享，并会**自动永久封禁您的账号且不予退款**。

**Q：使用机场代理会泄露我的支付宝或网银密码吗？**
**极少会。**
现代互联网中，几乎所有的 App 和网站（尤其是金融支付类）都采用了强制的 HTTPS / TLS 端到端加密。您的密码在离开手机之前就已经被加密成了天书。机场的服务器只能看到您的数据包流向了支付宝的服务器，但通常很难解开数据包看到里面的账号密码。

此外，只要您在使用代理软件时选择了“规则 / Rule”模式，国内银行 App 的流量根本就不会经过机场节点，而是直接从您的本地网络发出了，更加无须担忧。


## 更多高频问题集锦

### 购买机场套餐后，如何防止订阅被盗用？

## 一、 订阅链接 = 你的银行卡密码

机场系统只认订阅链接，不认人。只要别人拿到了你的订阅链接，就能把你的节点导入他的手机里，无限制地挥霍你的流量，而你还要替他买单。

## 二、 防盗三大纪律

1. **绝对不要截图发群里**：很多小白遇到问题，截图发到交流群求助，结果不小心把二维码或长链接暴露了，瞬间被脚本爬取盗用。
2. **不要使用来历不明的免费转换器**：很多非开源的订阅转换网站会在后台偷偷收集您的真实订阅链接拿去倒卖。
3. **定期重置**：如果您发现流量消耗异常快，或者经常被系统提示“超过设备并发数被踢下线”，请立刻登录机场网页，点击“重置订阅链接”！


### 公司内网/校园网屏蔽了代理软件怎么办？

## 一、 局域网封锁的原理

很多严格的公司内网或校园网，只允许 HTTP (80端口) 和 HTTPS (443端口) 流量通行，其他所有非标端口（如机场常用的 10086 端口）全部被防火墙物理掐断。这就是您在公司连不上节点的原因。

## 二、 突破方法

1. **寻找 443 端口节点**：在节点列表中，找找有没有端口号刚好是 443 的节点。这类节点通常使用 Trojan 或 Vless Reality 协议，流量完美伪装成正常的网页访问，公司网管通常很难拦截。
2. **更换机场**：部分高端机场专门针对企业级封锁做了优化，所有的入口服务器强制监听标准的 443 和 80 端口，实现全天候穿透内网。


### 如何判断我的节点是不是原生 IP？

## 方法一：IP 数据库查询

连上节点后，访问 `ipinfo.io` 或 `bgp.he.net`。查看页面上的 ASN 信息。如果显示的是大云厂商（如 Alibaba, Tencent, DigitalOcean），那大概率是机房广播 IP；如果显示的是当地的宽带运营商（如 HKT, Chunghwa Telecom），则有很大可能是原生 IP。

## 方法二：流媒体检测脚本

在节点连接状态下，使用开源的检测脚本（如 Github 上的 Netflix-Verify）。它会明确告诉你当前 IP 只能看 Netflix 自制剧，还是能看全部非自制版权剧（全解锁）。

## 方法三：欺诈分 (Fraud Score) 查询

访问 `scamalytics.com` 查 IP 欺诈分。分数越低（通常低于 15），说明这个 IP 越干净，越不容易在使用 ChatGPT 等服务时遇到频繁弹验证码或封号的问题。


### 机场晚高峰炸流量是什么原因？

## 一、 拥挤的国际出口

在中国大陆，所有的出境网络流量都必须经过三大运营商（电信、联通、移动）仅有的几个国际出口网关（如广州局、上海局）。每晚 8:00 - 11:00，数以亿计的网民在看视频、打游戏，国际出口就像早高峰的收费站，瞬间塞满。

## 二、 QoS 限速无差别打击

为了保证重要政企专线的畅通，运营商的路由器会在晚高峰开启 QoS（服务质量）限速，强行丢弃普通家用宽带出境的 UDP/TCP 数据包。这就是您的节点晚高峰丢包率飙升到 20% 以上的根源。

## 三、 常见解法之一：加钱上专线

要解决晚高峰卡顿，最为有效的物理手段之一就是避开拥堵的公网。这也是为什么 IPLC/IEPL 物理专线机场虽然昂贵，但在晚高峰依然能稳如老狗、秒开 4K 视频的原因。


### 手机开热点给电脑，电脑怎么走代理？

## 一、 为什么默认不行？

当您的手机开启小火箭或 Clash 翻墙后，代理隧道只作用于手机自身发出的流量。而通过 WiFi 热点接入的其他设备流量，会被手机系统直接丢进运营商网络，不会经过代理隧道。

## 二、 局域网共享功能 (Allow LAN)

**以 Clash Verge 为例**：
1. 电脑连接手机热点，确保电脑端开启了 Clash，并勾选了“允许局域网连接 (Allow LAN)”。
2. 记下电脑的局域网 IP（例如 192.168.43.5）和 Clash 的混合代理端口（默认 7890）。
3. 在另一台无法安装客户端的设备（如 Switch、电视盒子）的网络设置中，找到“手动代理”，填入上述 IP 和 7890 端口。

此时，这台设备的流量就会被发送到电脑的 Clash 中进行翻墙处理。


### 什么是倍率计费？为什么流量跑得这么快？

## 一、 为什么要有倍率？

机场维持不同国家的服务器成本是完全不同的。一台香港 IPLC 专线服务器的月租金，可能是美国普通公网服务器的几十倍。为了公平，机场引入了“倍率”机制。

## 二、 倍率的计算方式

*   **消耗额度 = 实际下载大小 × 节点倍率**
*   如果您使用倍率为 `1.0x` 的日本节点下载了 1GB 的电影，账单扣除 1GB。
*   如果您使用倍率为 `3.0x` 的沪日游戏专线下载了同样的 1GB 电影，账单将扣除 **3GB** 流量！

## 三、 省流技巧

在客户端的策略组中，将日常刷网页、看 YouTube 分配给低倍率（0.5x 或 1.0x）的普通中转节点；只在打跨国电竞游戏或外贸秒杀抢单时，手动切换到高倍率的专线节点。


### 机场节点全部 Timeout (超时) 的终极排查指南

## 步骤一：本地网络排查
先关闭代理软件。打开浏览器，看看能不能访问 `baidu.com`。如果百度也打不开，说明是你家的路由器断网了或者光纤欠费了。

## 步骤二：套餐状态排查
用手机 5G 流量登录机场网页后台。查看：
1. 您的套餐是否已经到期？
2. 您本月的流量配额是否已经使用至 100%？
如果已到期或耗尽，系统会自动掐断连接，表现就是所有节点超时。

## 步骤三：客户端与时间排查
确保您的电脑/手机系统时间是绝对准确的“北京时间”。如果您手动改过时间，请改回“自动同步”。时间不对会导致加密协议直接拒绝连接。

## 步骤四：一键更新订阅
如果以上都没问题，说明大概率是机场遭到了 GFW 封锁导致旧 IP 失效。只需在客户端中点击“更新订阅”，拉取服务商新换的 IP 即可恢复。


### 为什么看 YouTube 很快，看 Netflix 却很卡？

## 一、 什么是流媒体解锁？

Netflix 等平台为了保护版权，封杀了绝大多数数据中心（如阿里云、AWS）的 IP。为了让您能看 Netflix，机场必须在海外购买极度昂贵的“住宅宽带 IP”作为落地出口。

## 二、 木桶效应导致卡顿

当您看 YouTube 时，流量走的是宽敞的高速数据中心节点。而当您看 Netflix 时，流量被路由到了那个稀缺的“住宅 IP”上。住宅宽带的带宽通常很小（比如只有 20Mbps），且同时有很多人在挤，这就导致了虽然延迟低，但缓冲极慢的现象。

**解决办法**：在机场的节点列表中，寻找专门标注了“Netflix 专线优化”的高倍率节点，这些节点通常拥有更好的落地带宽。
