## 🔌 连接与节点问题

**Q：为什么导入订阅后，点击测速全部显示 Timeout (超时)？**
*   **排查 1**：您的本地网络是否正常？请先关闭代理，确认您能正常打开百度等国内网站。
*   **排查 2**：您的设备系统时间是否准确？Vmess 等协议对时间要求极其严格，设备时间与标准时间误差不能超过 90 秒。请在系统设置中开启“自动同步网络时间”。
*   **排查 3**：您的机场套餐是否已经到期？或者流量已经用尽被系统切断？请登录机场后台检查账单和仪表盘。

**Q：昨天用得好好的，今天突然连不上了怎么办？**
这通常是因为不可抗力导致节点 IP 被封，或者服务商更换了服务器。
**解决方法极其简单：更新订阅。**
在 Clash 中点击配置上的刷新按钮；在小火箭中向右滑动您的订阅名称，点击“更新”。拉取最新的节点配置后即可恢复正常。

**Q：这么多节点，香港、日本、美国到底选哪个？**
*   **日常网页浏览 / 刷推特**：首选**香港 (HK)** 或 **台湾 (TW)** 节点。物理距离近，延迟极低，网页可谓秒开。
*   **看视频 / 玩游戏**：首选**日本 (JP)** 节点。带宽充足，且到国际各大机房的路由非常优秀。
*   **外贸 / 跨境电商**：首选**美国 (US)** 节点。北美地区的网络环境审查最少，对于注册海外账号（如 ChatGPT、TikTok）最不容易触发风控。

## 🚀 速度与流量问题

**Q：为什么我买的 1000M 宽带，用机场测速只有 50M？**
翻墙速度不仅取决于您的本地宽带，还受制于“木桶效应”。数据需要经过您本地的小区光纤 -> 运营商国际出口 -> 海底光缆 -> 机场海外服务器。任何一个环节拥堵都会导致降速。在晚高峰时期，能够稳定保持在 50Mbps（足够流畅看 4K 视频）以上的机场，就已经算得上是非常优质的中高端机场了。

**Q：节点后面的 “x0.2” “x1.5” 是什么意思？**
这是机场通用的**倍率计费模式**。
*   `x1.0`：标准倍率。您看了 1GB 的视频，套餐就扣除 1GB 流量。
*   `x0.2`：通常是冷门地区或直连低成本节点。您用了 1GB，套餐只扣除 0.2GB。
*   `x2.0` / `x5.0`：通常是极其昂贵的 IPLC 物理专线节点。速度极快、延迟极低，但成本高昂。您用了 1GB，套餐将扣除 2GB 到 5GB 的额度。如果您流量不富裕，请谨慎挂着高倍率节点下载大文件。

**Q：流量用不完，下个月会结转累加吗？**
绝大部分机场采用的都是“按月清零”制。就像您的手机流量套餐一样，无论上个月剩下多少，次月结账日都会强制清零并重新发放当月额度。所以建议大家根据自己的实际用量，按需购买，避免浪费。

## 📱 设备与安全问题

**Q：我可以把节点分享给我的朋友使用吗？**
**绝对不要这么做。**
所有的机场系统都有严格的“异常 IP 检测”与“设备并发数检测”。如果系统发现您的账号同时在广州、北京、纽约的多个不同 IP 下登录，系统会判定您的账号被盗或恶意分享，并会**自动永久封禁您的账号且不予退款**。

**Q：使用机场代理会泄露我的支付宝或网银密码吗？**
**完全不会。**
现代互联网中，几乎所有的 App 和网站（尤其是金融支付类）都采用了强制的 HTTPS / TLS 端到端加密。您的密码在离开手机之前就已经被加密成了天书。机场的服务器只能看到您的数据包流向了支付宝的服务器，但绝对无法解开数据包看到里面的账号密码。

此外，只要您在使用代理软件时选择了“规则 / Rule”模式，国内银行 App 的流量根本就不会经过机场节点，而是直接从您的本地网络发出了，更加无须担忧。
