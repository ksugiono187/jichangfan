## 一、 为什么要测速？

优质的机场通常会提供几十甚至上百个节点。在面对密密麻麻的节点列表时，新手往往不知道该选哪一个。
此外，受国际网络波动影响，某个昨天还很快的节点今天可能就“炸”了。此时，学会利用 Clash 内置的测速功能来快速筛选出最优节点，就成了必备技能。

## 二、 如何在 Clash 中进行一键测速？

打开 Clash 客户端，进入 **“代理” (Proxies)** 选项卡，您会看到所有的节点策略组。

1. **寻找测速按钮**：在界面右下角（或右上角），通常会有一个形如**雷达 📡**、**闪电 ⚡** 或 **WiFi** 的图标。
2. **执行测试**：点击该图标。此时，Clash 会在后台并发地向所有的服务器发送 HTTP 请求（通常是请求 `http://www.gstatic.com/generate_204`，这是一个极快且无内容的谷歌服务器）。
3. **查看结果**：几秒钟后，每个节点的右侧都会出现一个数值（如 `35ms`, `120ms` 或 `Timeout`）。

## 三、 如何解读测速结果？

测速出来的数值，代表的是您的设备通过该节点，完成一次完整的 TCP 握手并收到 HTTP 响应的总时间。

*   **绿色数字 (例如 15ms - 80ms)**：极佳！通常是 IPLC 专线或优质中转节点，强烈建议作为主力日常节点。
*   **黄色/橙色数字 (例如 100ms - 200ms)**：一般。网页加载会有轻微延迟，但看视频缓冲完后不受影响。
*   **红色数字 (例如 300ms 以上)**：较差。延迟极高，除非没有其他选择，否则不建议使用。
*   **Timeout / Error**：超时无响应。代表该节点目前处于离线、维护或被封锁状态，**绝对不要选择**。

## 四、 高级技巧：利用“自动测速 (URL-Test)”组

如果您觉得每次手动点测速、手动切节点太麻烦，Clash 早就为您准备了完美的自动化方案。

绝大多数机场在下发的 Clash 订阅中，都会为您预设一个名为 **“自动选择” (Auto / URL-Test)** 的特殊策略组。
*   **它的原理是**：每隔一段时间（例如 300 秒），Clash 就会在后台自动对该组内的所有节点进行一次测速。
*   然后，它会**自动将您的网络流量切换到当前延迟最低的那个节点上**。

**操作建议**：在日常使用中，您只需要在最顶级的策略组（如 PROXY 组）中选中“自动选择”，您就可以完全忘记节点的存在。只要机场的服务器没有大部分宕机，Clash 就会自动帮您尝试切换至延迟更低的节点。

*注意：不建议在玩对外服游戏时使用“自动选择”，因为后台频繁切换 IP 可能会导致游戏断线或封号。玩游戏时请手动指定一个稳定的专线节点。*
