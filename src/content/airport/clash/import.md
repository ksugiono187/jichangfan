## 准备工作

在开始之前，请确保您已经完成以下两步：
1. 已经购买了可靠的机场套餐，并能够登录机场的网页后台。
2. 已经在电脑上下载并安装了最新的 **Clash 客户端**（强烈建议使用 **Clash Verge Rev**）。

## 第一步：获取 Clash 订阅链接

1. 登录您的机场网页后台（通常称为“仪表盘”或“用户中心”）。
2. 在首页寻找类似 **“便捷导入”**、**“一键订阅”** 或 **“使用教程”** 的板块。
3. 找到名为 **“复制 Clash 订阅链接”** 的按钮，点击它。此时，一串以 `http` 或 `https` 开头的长链接已经复制到了您的系统剪贴板中。
   *(注意：请认准 Clash 专属链接，不要复制错成 V2Ray 或普通的 Base64 链接)*

## 第二步：在 Clash 中导入配置

1. 启动您电脑上的 Clash Verge 软件。
2. 在软件界面的左侧导航栏中，点击 **“订阅” (Profiles / Subscriptions)** 选项卡。
3. 在页面顶部，您会看到一个输入框。将刚刚复制的订阅链接**粘贴**到该输入框中。
4. 点击输入框右侧的 **“导入” (Import / Download)** 按钮。
5. 此时软件会向机场服务器发起请求。几秒钟后，列表中会出现一个新增的配置文件卡片，上面会显示您的机场名称、套餐剩余流量以及到期时间。
6. **极其关键的一步**：用鼠标**点击**选中这个刚下载的卡片。卡片变成蓝色或高亮状态，才代表该配置已被成功激活。

## 第三步：开启系统代理，正式起飞

1. 配置文件选中后，点击左侧导航栏的 **“代理” (Proxies)** 选项卡。
2. 在这里，您能看到机场为您提供的所有节点。建议在顶部选择 **“规则” (Rule)** 模式，这样国内网站直连，国外网站走代理，体验最佳。
3. 您可以手动点击选择一个香港或日本的节点。
4. 点击左侧导航栏的 **“设置” (Settings)**。
5. 找到 **“系统代理” (System Proxy)** 开关，将其**打开**。

🎉 恭喜！您现在已经成功接入国际互联网。您可以尝试在浏览器中打开 `www.google.com` 或 `www.youtube.com` 来验证连接是否成功。

## 常见问题排查

*   **无法下载配置文件，提示 Network Error？**
    *   请检查您的本地网络是否正常。部分机场的订阅域名可能被墙，您可以尝试在手机上用 5G 流量热点连接电脑进行下载，或者联系机场客服获取备用订阅地址。
*   **开启系统代理后，连国内网站也打不开了？**
    *   大概率是因为您选择的节点已经失效。请返回“代理”页面，点击右下角的雷达图标进行测速，并切换到一个延迟带有绿色数字的节点。
