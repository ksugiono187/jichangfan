## Clash 核心概念解析：Proxy、Rule 与 Provider

## 一、 代理 (Proxy) 与策略组 (Proxy Group)

在 Clash 中，每一个具体的服务器节点就是一个 Proxy。为了方便管理，Clash 引入了“策略组”的概念。
您可以将多个节点放入一个策略组中，并为其指定选择逻辑（如自动测速选择、手动选择、负载均衡等）。

## 二、 规则 (Rule)

Clash 强大的核心在于其分流规则。规则决定了您的网络请求是直接连接（DIRECT）、走代理（PROXY）还是被拦截（REJECT）。常见的规则类型包括域名匹配 (DOMAIN-SUFFIX)、IP 匹配 (IP-CIDR) 和地理位置匹配 (GEOIP)。

## 三、 Provider 机制

Provider 允许将节点列表或规则列表从主配置文件中分离出来，通过远程链接动态更新。这就是为什么您可以一键更新机场订阅，而不会覆盖您自己写的本地分流规则的原因。

## 如何在 Clash 中自定义分流规则

## 一、 YAML 语法基础

Clash 的配置文件使用 YAML 格式。在 `rules:` 字段下，规则的匹配优先级是从上到下的。一旦匹配命中，后续规则将不再执行。

## 二、 常用分流规则示例

*   `DOMAIN-SUFFIX,openai.com,美国节点`：让所有 ChatGPT 的请求强制走“美国节点”策略组。
*   `DOMAIN-KEYWORD,baidu,DIRECT`：只要域名包含 baidu，就直连。
*   `IP-CIDR,192.168.0.0/16,DIRECT`：局域网 IP 直连，保证您能正常访问家里的路由器后台。

## 三、 规则集的引用

为了避免配置文件过于臃肿，推荐使用 `rule-providers` 引用各大开源社区维护的规则集（如 Loyalsoldier 规则集）。

## Clash Meta (mihomo) 内核新特性盘点

## 一、 支持最新协议

原版 Clash 不支持 Vless Reality 和 Hysteria 等新协议。Meta 内核第一时间合并了这些特性的支持，让用户免受 GFW 封锁之苦。

## 二、 强大的 DNS 引擎

Meta 内核重写了 DNS 处理逻辑，彻底解决了困扰多年的 DNS 泄露和域名解析污染问题。配合 Fake-IP 机制，网页首屏加载速度显著提升。

## 三、 规则集拓展

Meta 支持直接读取 GEOSITE 和 GEOIP 数据库文件，极大精简了配置文件的体积，提高了分流匹配的效率。

## Clash 搭配软路由 (OpenWrt) 的家庭组网方案

## 一、 软路由的优势

在 OpenWrt 路由器上部署 OpenClash，您的手机、平板、电视盒子甚至扫地机器人都不需要安装任何代理客户端。连上 WiFi，直接就能访问国际互联网。

## 二、 OpenClash 基础配置

1. 在路由器后台上传并安装 OpenClash 插件。
2. 导入机场订阅链接。
3. 选择“Fake-IP (混合)”模式，这是目前软路由翻墙解析 DNS 最快、最兼容的模式。

## 三、 性能瓶颈警告

加解密代理流量非常消耗 CPU 算力。如果您家是千兆宽带，请确保您的软路由采用 J4125、N100 等高性能 x86 处理器，普通的 ARM 路由器可能会跑不满带宽。

## 解决 Clash 无法更新订阅的常见错误

## 1. Network Error (网络错误)

这通常是因为机场的订阅域名被 GFW 污染了。**解决办法**：用手机开 5G 热点给电脑更新；或者向机场客服索要备用订阅地址。

## 2. YAML Parse Error (解析错误)

这意味着机场下发的数据格式有语法错误。**解决办法**：有可能是机场服务端正在维护，或者您的流量用尽导致服务器返回了 HTML 报错页面而不是 YAML 文件。登录机场网页查看账号状态即可。

## 3. 提示 x509 证书错误

您的电脑系统时间不对，或者系统的根证书太老。请在 Windows 设置中同步系统时间。

## Clash TUN 虚拟网卡模式详解

## 一、 为什么需要 TUN 模式？

传统的“系统代理”实际上只是在系统的 IE 设置中加了一个 HTTP 代理。很多软件（如各种游戏客户端、微软商店应用 UWP、终端命令行）根本不理会这个设置，导致无法翻墙。

## 二、 TUN 的工作原理

TUN 模式会在您的系统中创建一张虚拟网卡。它会直接接管操作系统的底层网络栈（Layer 3），将所有的网络流量（TCP/UDP）强行吸入 Clash 进行处理。

## 三、 如何开启

在 Clash Verge 中，点击“设置” -> “Clash 核心”，找到“TUN 模式”开关。开启前，请确保您以管理员身份运行了软件，或安装了相关的 Service 服务组件。

## Clash Verge Rev 进阶设置指南

## 一、 Merge 融合脚本

当机场下发的配置文件不满足您的要求时，您可以使用 Verge 的 Merge 功能，用 JavaScript 脚本在配置加载前动态修改参数。比如强制添加一个特定网站的直连规则。

## 二、 界面与托盘自定义

在设置中，您可以开启悬浮窗实时查看网速，并自定义系统托盘图标的颜色，以便在茫茫图标中一眼识别当前的代理状态。

## 三、 快捷键配置

熟练设置系统级快捷键（如 `Ctrl+Alt+P` 快速切换全局系统代理开关），能极大提升您的冲浪效率。
